# Demo photo provenance

The default wardrobe uses 32 real photographs bundled in `backend/assets/photos/`. The index matches `app.seed.DATA`; `photo-manifest.json` records each source and license. Images are licensed under the [Pexels License](https://www.pexels.com/license/), separately from the MIT code license. They are application demo assets, not a stock photo library. Do not imply photographer or model endorsement.

Some photographs show models or other garments. Each card refers to its named garment; this is not virtual try-on. Colors and categories were visually reviewed; warmth and formality are manually assigned illustrative ratings, not verified textile properties. User uploads remain private and are outside these asset licenses. Legacy `00.png`–`31.png` illustrations remain CC0.
